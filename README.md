# MAT
Server Emulator for Mission Against Terror: City Under Fire 
``2011`` Client Ver. 





# Done
* Nickname/Character Creation (Nickname already exists)
* Friends List (Online/Offline detection)
* Channel Player List
* Inventory
* Enter Room
* Create Room
* Room List
* Player Replication Data: Crouch, Walking, Running, XYZ Movement/Rotation, Ammo
* Gameplay Replication: Scores, Game time, Scoreboards, etc.
* FOV Changer
* Viewmodel FOV Changer
* FPS Unlocker (originally locked at around 80 FPS)
